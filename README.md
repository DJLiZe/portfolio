# Student Portfolio Starter

A starter kit for a personal portfolio website: your art and writing,
published free on the web with **GitHub Pages**.

It's for someone who has **never used git or GitHub before**. Setting it up
is the lesson: you'll create your own GitHub account and repository, make your
first commit, and see your site go live. Then you'll swap the example pieces
for your own work.

**Start here: [GETTING-STARTED.md](GETTING-STARTED.md)**

## What's inside

| Path | What it holds |
| --- | --- |
| `source/art/` | Your original, full-quality art files. Kept safe in git, not shown on the site. |
| `source/writing/` | The original text of your writing, as plain text files. |
| `docs/` | The website itself. GitHub Pages publishes this folder. |
| `docs/assets/img/` | Smaller, web-sized copies of your art that the site shows. |
| `docs/assets/css/style.css` | How the site looks: colors, fonts, layout. |
| `content.yaml` | A list of every piece: where the original is and where it's published. |
| `resize-image.sh` | A script that makes a web-sized copy of an image (on a Mac). |

There's no build step, framework, or anything to install. The whole site is
plain HTML and CSS files you can open and read.

## Growing it later

You can add other things next to the portfolio later without changing what's
already here. For example, a `code/` folder for programming projects, or a
`projects/` folder for other work. Only `docs/` gets published, so new
folders stay out of the way until you link to them.
